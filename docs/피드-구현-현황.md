# 피드(Feed) 구현 현황 및 계획

> 2026-11-04 기준. 피드 도메인의 전체 구현 상태를 추적하는 문서

---

## 1. 아키텍처 요약

```
[프론트엔드]                        [백엔드]
/main (추천/팔로잉 탭)         ←→  GET  /api/v1/feeds?type=
/feeds/[feedId] (상세)         ←→  GET  /api/v1/feeds/{feedId}
/my/feeds (내 피드)            ←→  GET  /api/v1/users/me/feeds
피드 작성 (FeedComposer)       ←→  POST /api/v1/feeds
피드 수정 (/feeds/[id]?edit=1) ←→  PUT  /api/v1/feeds/{feedId}
피드 삭제 (FeedMenu)           ←→  DELETE /api/v1/feeds/{feedId}
좋아요/리포스트/북마크 버튼     ←→  POST/DELETE /api/v1/feeds/{feedId}/like|repost|bookmark
댓글 섹션                      ←→  GET/POST /api/v1/feeds/{feedId}/comments
```

- **페이지네이션**: 커서 기반 (`cursor` + `size` → `nextCursor` + `hasNext`)
- **추천 알고리즘**: 점수 기반(팔로잉 +50, 좋아요/댓글/리포스트 가중치, 태그 매칭, 시간 감쇠) + 트렌딩 50:50 혼합
- **응답 래핑**: 모든 응답은 `{ "data": ... }` 형태 (`ApiResponse<T>`)

## 2. 백엔드 파일 구조

```
com/dipsource/
├── entity/feed/
│   ├── Feed.java              피드 엔티티 (content 500자, status, 카운트 필드, JSONB)
│   ├── FeedStatus.java        ACTIVE / HIDDEN / DELETED
│   ├── FeedLike.java          좋아요 (복합PK: user_id + feed_id)
│   ├── FeedRepost.java        리포스트 (복합PK)
│   ├── FeedBookmark.java      북마크 (복합PK)
│   ├── FeedUserId.java        위 셋의 공유 복합PK @Embeddable
│   ├── FeedComment.java       댓글 (parent로 대댓글 계층, likeCount, deletedAt)
│   ├── FeedCommentLike.java   댓글 좋아요
│   ├── FeedCommentLikeId.java 댓글 좋아요 복합PK
│   ├── FeedTag.java           피드-태그 N:M
│   ├── FeedTagId.java         복합PK (feed_id + tag_id)
│   └── FeedVote.java          투표 참여 (optionIndex, 1인 1투표)
│
├── dto/feed/
│   ├── FeedCreateRequest.java   생성 요청 (content, demoId, tagIds, imageUrls, linkUrl, pollOptions)
│   ├── FeedUpdateRequest.java   수정 요청 (content만)
│   ├── FeedResponse.java        피드 응답 (⚠️ liked/reposted/bookmarked/following 항상 false)
│   ├── FeedCursorResponse.java  커서 페이지네이션 래퍼
│   └── FeedSearchItemResponse.java  검색 결과 항목
│
├── repository/feed/
│   ├── FeedRepository.java      추천/트렌딩/팔로잉/관심태그/최신/내 피드 쿼리
│   ├── FeedSearchRepository.java 검색 전용
│   └── FeedTagRepository.java   피드↔태그 조회
│
├── service/feed/
│   ├── FeedService.java              CRUD + 내 피드 목록
│   ├── FeedRecommendationService.java 추천/팔로잉/트렌딩/비로그인 피드
│   ├── FeedSearchService.java        검색 인터페이스
│   ├── impl/FeedSearchServiceImpl.java 검색 구현체
│   └── TagWeightService.java         좋아요/댓글/북마크 시 태그 가중치 갱신 (추천 학습)
│
└── controller/feed/
    ├── FeedController.java              CRUD (POST/GET/PUT/DELETE)
    ├── FeedRecommendationController.java 목록 조회 (추천/팔로잉/트렌딩)
    └── MyFeedController.java            내 피드 목록 (GET /users/me/feeds)
```

## 4. 구현 체크리스트

### 4-1. 피드 기본 CRUD

- [x] 피드 작성 (`POST /feeds`) — 백엔드 + 프론트 FeedComposer
- [x] 피드 단건 조회 (`GET /feeds/{feedId}`) — 백엔드 + 프론트 FeedDetail
- [x] 피드 수정 (`PUT /feeds/{feedId}`) — 백엔드 + 프론트 FeedEditForm
- [x] 피드 삭제 (`DELETE /feeds/{feedId}`) — 백엔드 소프트삭제 + 프론트 FeedMenu
- [x] 피드 작성 시 태그 첨부 — 백엔드 FeedTag 저장
- [ ] 피드 작성 시 이미지 첨부 — 백엔드 imageUrls 필드 있음, 프론트 버튼 disabled 상태
- [ ] 피드 작성 시 링크 첨부 — 백엔드 linkUrl 필드 있음, 프론트 버튼 disabled 상태

### 4-2. 피드 목록 조회

- [x] 추천 피드 (`GET /feeds?type=recommended`) — 점수 기반 + 트렌딩 혼합
- [x] 팔로잉 피드 (`GET /feeds?type=following`) — 팔로잉 사용자 글 최신순
- [x] 트렌딩 피드 — 1h/6h/24h 좋아요 가중치
- [x] 비로그인 피드 — 트렌딩 50% + 최신 50%
- [x] 관심 태그 기반 피드 — 신규 사용자(활동 없음)용
- [x] 커서 기반 페이지네이션 — nextCursor + hasNext
- [x] 태그 목록 (`GET /tags`) — TagController
- [x] 내 피드 목록 (`GET /users/me/feeds`) — 백엔드 완료
- [x] 내 피드 목록 — 프론트 `/my/feeds` 구현됨

### 4-3. 좋아요·리포스트·북마크

- [x] 엔티티 정의 — FeedLike, FeedRepost, FeedBookmark (복합PK)
- [x] 프론트 UI — FeedActions 버튼 + 낙관적 UI (useToggle)
- [x] 프론트 서버 액션 — toggleLike, toggleRepost, toggleBookmark 정의됨
- [x] 좋아요 API (`POST/DELETE /feeds/{feedId}/like`) — FeedEngagementService + FeedController
- [ ] 리포스트 API (`POST/DELETE /feeds/{feedId}/repost`) — 백엔드 미구현
- [x] 북마크 API (`POST/DELETE /feeds/{feedId}/bookmark`) — FeedEngagementService + FeedController + 유닛 테스트
- [ ] FeedResponse에 liked/reposted/bookmarked 실제 상태 반영 — 현재 항상 false
- [ ] FeedResponse에 following 실제 상태 반영 — 현재 항상 false
- [x] 좋아요 시 TagWeightService 연동 — like/unlike 시 ±1
- [x] 북마크 시 TagWeightService 연동 — bookmark/unbookmark 시 ±1

## 5. 알려진 이슈

| # | 이슈 | 영향 | 우선순위 |
|---|------|------|----------|
| 1 | `FeedResponse`의 liked/reposted/bookmarked/following이 항상 false | 좋아요 API는 동작해도 새로고침 시 버튼이 꺼진 것처럼 보임 | 순서 3에서 수정 |
| 2 | 프론트 Feed 타입에 imageUrls/linkUrl/pollOptions 없음 | 이미지/링크/투표 첨부 피드가 프론트에서 표시 안 됨 | 이미지 첨부 기능 구현 시 |
| 3 | FeedComposer 이미지/링크 버튼 disabled | 사용자가 이미지/링크 첨부 불가 | 중 |
| 4 | 댓글 수(commentCount)가 feeds 테이블에 있으나 갱신 로직 없음 | 댓글 API 구현 시 같이 처리 | 댓글 구현 시 |
