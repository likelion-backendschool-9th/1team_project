## 기준을 판단하는 순서

1. 실제 동작은 현재 코드와 설정 파일을 기준으로 확인합니다.
2. DB 설계 초안은 `erd-v2.sql`과 테이블 정의서를 대조합니다. 서로 다르면 어느 쪽이 최신인지 확인하고 수정합니다.
3. 개발 규칙은 BACKEND.md와 FRONTEND.md를 따릅니다. 기획/WBS 문서의 API 경로는 확정 구현 계약으로 간주하지 않습니다.
4. 문서를 갱신할 때는 관련 문서만 수정하고, 이 표의 링크·상태도 함께 점검합니다.

> 현재 저장소는 기능별 구현이 진행 중인 상태입니다. 설계 문서에 기능이 적혀 있어도 코드에 구현됐다는 뜻은 아닙니다.
