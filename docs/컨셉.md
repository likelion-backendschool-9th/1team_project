# 찍먹 디자인 컨셉

## 서비스 컨셉

**"개발자의 소스를 맛보다"**

비스킷을 초콜릿 소스에 찍어 먹듯, 남의 코드를 부담 없이 한 입 맛보는 경험. 무겁지 않고, 가볍게 체험하고, 재밌으면 더 파고드는 흐름.

## 톤앤매너

| 항목 | 방향 |
|------|------|
| 분위기 | 친근하고 캐주얼. 개발자 커뮤니티의 편한 분위기 |
| 말투 | 반말/존댓말 혼용 (버튼·CTA는 "~해보세요", 설명은 "~합니다") |
| 비유 | 음식·요리 비유 적극 활용 ("찍먹하기", "도토리", "소스를 맛보다") |
| 이모지 | 서비스 내 제한적 사용 (🍽 로고, 피드·방명록에서는 사용자 자유) |

## 핵심 키워드

- **찍먹** — 가볍게 체험. 클릭 한 번으로 데모 실행
- **미니홈피** — 싸이월드 감성의 개인 공간. TODAY/TOTAL, 방명록, 스킨
- **도토리** — 싸이월드 오마주 가상화폐. 충전·선물·결제
- **파도타기** — 랜덤 미니홈피 방문. 새로운 개발자 발견

## UI 방향

| 영역 | 스타일 |
|------|--------|
| 레이아웃 | 모바일 우선 반응형. 피드는 카드형, 데모는 그리드형 |
| 미니홈피 | 싸이월드 감성 + 현대적 레이아웃. 스킨/테마 교체 가능 |
| 관리자 | 깔끔한 대시보드. 통계 카드 + 테이블 중심 |
| 네비게이션 | 상단 헤더 (로고, 검색, 메뉴) + 사이드바 (피드, 순위 등) |
| 데모 카드 | 썸네일 + 제목 + 작성자 + 좋아요·체험 횟수 + "찍먹하기" 버튼 |
