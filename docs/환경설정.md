# 찍먹 환경 설정 가이드

> 로컬 개발 환경 세팅부터 실행까지.

---

## 1. 사전 준비

| 도구 | 버전 | 확인 명령 |
|------|------|----------|
| Java (JDK) | 21 | `java -version` |
| Node.js | 20+ | `node -v` |
| PostgreSQL | 16 | `psql --version` |
| Docker / Docker Compose | 최신 | `docker -v` |
| Git | 최신 | `git --version` |

---

## 2. 프로젝트 클론

```bash
git clone <레포 URL>
cd team_project
```

---

## 3. 데이터베이스 설정

### 방법 A: 로컬 PostgreSQL

```bash
# DB 생성
psql -U postgres
CREATE USER dipsource WITH PASSWORD 'dipsource';
CREATE DATABASE dipsource OWNER dipsource;
\q
```

### 방법 B: Docker로 DB만

```bash
docker run -d \
  --name dipsource-db \
  -e POSTGRES_DB=dipsource \
  -e POSTGRES_USER=dipsource \
  -e POSTGRES_PASSWORD=dipsource \
  -p 5432:5432 \
  postgres:16
```

테이블은 Spring Boot 시작 시 JPA `ddl-auto: update`로 자동 생성된다.

---

## 4. 백엔드 실행

```bash
cd backend

# 빌드
./gradlew build

# 실행
./gradlew bootRun
```

- 기본 포트: `http://localhost:8080`
- API 기본 경로: `http://localhost:8080/api/v1/`

### 환경변수

`application.yml`의 기본값으로 로컬 실행 가능. 변경이 필요하면 환경변수로 덮어쓴다.

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://localhost:5432/dipsource` | DB 접속 URL |
| `SPRING_DATASOURCE_USERNAME` | `dipsource` | DB 사용자 |
| `SPRING_DATASOURCE_PASSWORD` | `dipsource` | DB 비밀번호 |
| `JWT_SECRET` | (설정 필요) | JWT 서명 키 |
| `GITHUB_CLIENT_ID` | (설정 필요) | GitHub OAuth 앱 ID |
| `GITHUB_CLIENT_SECRET` | (설정 필요) | GitHub OAuth 앱 시크릿 |
| `KAKAO_CLIENT_ID` | (설정 필요) | 카카오 앱 키 |
| `GOOGLE_CLIENT_ID` | (설정 필요) | 구글 OAuth 클라이언트 ID |
| `GOOGLE_CLIENT_SECRET` | (설정 필요) | 구글 OAuth 클라이언트 시크릿 |

## 5. 프론트엔드 실행

```bash
cd frontend

# 의존성 설치
npm install

# 개발 서버
npm run dev
```

- 기본 포트: `http://localhost:3000`

### 환경변수

`frontend/.env.local`을 생성한다 (`.gitignore`에 포함됨):

```env
# 백엔드 API 주소 (서버 컴포넌트에서 사용)
API_ORIGIN=http://localhost:8080

# 사이트 URL (메타데이터, OG 이미지)
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

`.env.local.example`을 레포에 커밋해두고, 각자 복사해서 사용한다.

---

## 6. Docker Compose (전체 실행)

프로젝트 루트에서:

```bash
docker compose up -d
```

| 서비스 | 포트 | 설명 |
|--------|------|------|
| `nginx` | 80, 443 | 리버스 프록시 |
| `frontend` | 3000 | Next.js |
| `backend` | 8080 | Spring Boot |
| `db` | 5432 | PostgreSQL |

개발할 때는 DB만 Docker로 띄우고 백엔드·프론트는 로컬에서 직접 실행하는 게 편하다.

---

## 7. 확인

모든 서비스가 정상 실행되면:

| 확인 항목 | 방법 |
|----------|------|
| DB 접속 | `psql -h localhost -U dipsource -d dipsource` |
| 백엔드 | `curl http://localhost:8080/api/v1/` (응답 확인) |
| 프론트엔드 | 브라우저에서 `http://localhost:3000` |

---

## 8. 주의 사항

- `.env`, `.env.local`은 절대 커밋하지 않는다 (`.gitignore`에 포함)
- `JWT_SECRET`, OAuth 시크릿 등 비밀값은 팀 내부에서만 공유한다
- DB 비밀번호 `dipsource`는 로컬 개발용이다. 배포 환경에서는 반드시 변경한다
- `ddl-auto: update`는 개발용이다. 운영에서는 `validate`로 변경하고 마이그레이션 도구를 사용한다
